# Superstore Sales Dashboard

## Overview
This project is an interactive Excel dashboard developed to analyze Superstore sales data and uncover meaningful business insights. The dashboard uses Pivot Tables, Pivot Charts, Slicers, and KPI Cards to provide a comprehensive view of sales performance across regions, customer segments, shipping modes, and cities.

## Key Metrics
- Total Sales: ₹58,20,182
- Total Quantity Sold: 25,123
- Total Transactions: 9,994
- Average Sales per Transaction: ₹582.37

## Dashboard Features
- Dynamic KPI Cards
- Region-wise Analysis
- Year-wise Filtering
- Ship Mode Distribution
- Monthly Quantity Trend
- Top 5 Cities by Sales
- Category-wise Transactions
- Customer Segment Analysis
- Interactive Slicers for Data Exploration

## Business Insights
- Standard Class shipping accounts for the majority of orders.
- West region contributes the highest order volume.
- November recorded the highest quantity sold.
- New York City generated the highest sales among all cities.
- Consumer segment contributes the largest share of total quantity ordered.
